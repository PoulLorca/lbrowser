# LBrowser

**LBrowser: Go Further!**

![LBrowser Logo - Submarine](https://poullorca.github.io/lbrowser-site/submarine.svg) LBrowser (Little Browser) is a compact, open-source web browser built for privacy and exploration. Navigate the standard web securely and easily access alternative networks like Tor, I2P, Zeronet, and Hyphanet through integrated Docker container modes.

## Why LBrowser?

In a web increasingly focused on tracking and data harvesting, LBrowser offers a different path. Our core philosophy is simple: your data belongs to you. We never collect, store, sell, or use your Browse information for any purpose, including training AI models. LBrowser uses the reliable, open-source Chromium rendering engine via a webview, focusing solely on helping you find what you're looking for, wherever it is on the web.

## Features

* **Seamless Multi-Network Access:** Easily switch between the standard web and decentralized/privacy networks (Tor, I2P, Zeronet, Hyphanet) via simple Docker mode toggles. (Requires Docker installed and running).
* **Built-in Privacy & Security:** Zero data tracking, collection, or selling. Includes an integrated ad and tracker blocker. Focus on secure, curated Docker images.
* **Lightweight & Efficient:** Designed to be small and performant.
* **Open Source:** Transparent code allows for community review and contributions.
* **Media Extraction Mode:** Effortlessly extract and download all multimedia content from a page.
* **No Default Search Engine Bias:** The address bar does not force searches to any specific engine, honoring your choice of how and where to search.
